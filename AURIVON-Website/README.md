# AURIVON Website

## Pages
- `index.html` — main Coming Soon landing page.
- `contact.html` — separate contact / registration page. It opens from the Contact navigation and Register Your Store buttons.
- `assets/` — logo and supplied website images.

## Open in VS Code
1. Extract this ZIP.
2. In VS Code, choose **File → Open Folder** and select this folder.
3. Install the **Live Server** extension if you do not already have it.
4. Right-click `index.html` and choose **Open with Live Server**.
5. Click **Contact** or **Register Your Store** to open the separate contact page.

The footer displays Instagram, Facebook, LinkedIn, and X icons. The Instagram icon links to the AURIVON profile; add the other profile links when available.

## Publishing
- This is a static site. Publish this folder with `index.html` as the entry page, keeping `contact.html` and `assets/` alongside it.
- The contact form uses `mailto:` and opens the visitor's email app; connect a form service or backend if submissions should work directly on the site.
- Add the Facebook, LinkedIn, and X profile URLs before making those icons clickable.
- Choose a hosting provider and domain; this project does not have provider-specific deployment configuration yet.
